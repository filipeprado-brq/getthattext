# Mapa: getthattext

## Destination

Uma **spec de MVP pessoal** do getthattext — ferramenta de barra de menu do macOS que transcreve fala, melhora o texto e o entrega pela área de transferência — com todas as decisões travadas e escritas, pronta pra alguém sentar e implementar. Uso pessoal do autor; não há distribuição a terceiros.

## Notes

**Domínio:** app de ditado para macOS 15 (Sequoia, Apple Silicon). Clique no ícone da barra (ou atalho global de toggle) → captura de áudio → `whisper.cpp` local → reescrita via Groq → **texto no clipboard**, colado à mão pelo usuário. O app nunca toca outro aplicativo.

**Arquitetura decidida:** Electron puro — **nenhum addon nativo**. O único binário externo é o `whisper-cli`.
- `whisper-cli` local via child process (áudio bruto nunca sai da máquina), **sem `--vad`** — o VAD roda separado, como portão (ligá-lo na transcrição engole conteúdo)
- **Dois modelos em disco:** `large-v3-turbo-q5_0` (547 MB) e o VAD Silero (885 KB), ambos baixados no primeiro uso. O VAD roda **antes**, como portão — nunca dentro da transcrição
- `groq-sdk` (JS oficial) reescreve o texto cru — este passo é nuvem, por decisão explícita
- **`globalShortcut` do Electron puro** para o atalho de toggle — toggle precisa só de key-down, então **não há addon nativo para o atalho**. O ícone da barra é o gatilho principal (esquerdo alterna, direito abre configurações)
- **O texto vai para o clipboard.** Nenhuma injeção, nenhum `CGEvent`, nenhuma Accessibility API. **Uma única permissão TCC: Microfone.** O app nunca aparece em Privacidade > Acessibilidade
- `Tray` API para o ícone — gatilho **e** indicador. Monocromático `template` exceto **vermelho ao gravar**, respirando a 1,7 s
- `getUserMedia` + `AudioContext` pra captura e resampling

**Skills a consultar em cada sessão:** `/grilling` e `/domain-modeling` como padrão; `/prototype` para tickets `prototype`; `/research` (subagente) para tickets `research`.

**Preferências permanentes deste esforço:**
- Planejar, não construir. Os tickets produzem decisões, não código de produção. Protótipos são descartáveis.
- Conversas em português.
- Toda decisão de privacidade é explícita: áudio bruto fica local, texto reescrito vai pro Groq. Qualquer proposta que mude isso reabre a decisão, não passa em silêncio.
- Este diretório **não é um repo git**. Achados de research vão pra `.scratch/getthattext/research/<slug>.md`, não pra branches.
- **Subagentes de research não tocam a sessão de desktop do usuário.** Nada de sintetizar teclado/mouse, escrever no pasteboard, chamar Accessibility API contra apps em execução, abrir ou fechar apps GUI, ou mudar configuração de sistema. Um agente já injetou texto de teste na janela de Terminal em foco por engano. O que só puder ser resolvido empiricamente sai marcado como não verificado e vira ticket de teste manual.

## Decisions so far

<!-- índice — uma linha por ticket resolvido -->

- [API do Groq](issues/05-api-do-groq.md) — `openai/gpt-oss-20b` com raciocínio desligado, chave no Keychain via `safeStorage` async (sem módulo nativo), cliente com `timeout: 10_000, maxRetries: 1`. Passo Groq custa **~0,9–1,4 s**. Free tier limita a ~8–9 reescritas/minuto.
- [Captura de áudio no Electron](issues/04-captura-de-audio-no-electron.md) — captura no renderer, `AudioContext({sampleRate: 16000})`, `AudioWorkletNode` → WAV escrito à mão, entregue por **stdin** (`whisper-cli -f -`, verificado no fonte). O Chromium **adia o início da captura em 5 s após o Mac acordar**, então "gravando" só acende quando o áudio chega. Mic ocupado por Zoom **não** bloqueia.
- [whisper.cpp via child process](issues/03-whisper-cli-via-child-process.md) — **`large-v3-turbo-q5_0`** (547 MiB: disco de `small`, qualidade de `large-v2`), baixado no primeiro uso; binário buildado no CI e embarcado, **nenhum wrapper npm serve**. Metal liga sozinho, Core ML rejeitado. (`--prompt` foi **descartado** depois, em [Onde entra o dicionário customizado](issues/10-onde-entra-o-dicionario-customizado.md); o limite real são 223 tokens, não 224.)
- [Onde entra o dicionário customizado](issues/10-onde-entra-o-dicionario-customizado.md) — **`--prompt` do whisper descartado** (é apagado após a primeira janela de 30 s e some de vez no áudio difícil; modos de falha destrutivos). Dicionário entra como **substituição determinística antes do Groq** + lista de termos no prompt do Groq. Formato `dictionary.json` com `heard[]` opcional.
- ~~[Key-up global no macOS](issues/02-key-up-global-no-macos.md)~~ **(superado em parte — toggle não usa key-up; a shortlist de teclas sobrevive)** — **a premissa do ticket estava errada: não precisa de keylogger.** `RegisterEventHotKey` + `kEventHotKeyReleased` é escopado a uma combinação, entrega press E release, e **não exige nenhuma permissão TCC**. `uiohook-napi` vira plano B. `fn` descartada (a Apple reserva Fn-D pro ditado nativo). Default sugerido `⌃⌥⌘G`.
- ~~[Injeção de texto no input focado](issues/01-injecao-de-texto-no-input-focado.md)~~ **(superado — não se injeta mais)** — **Pasteboard + `⌘V` via `CGEvent`**, medido nesta máquina. A **Accessibility API foi descartada para escrita**: falha nos apps Electron por padrão, o `set` mente sobre sucesso, e quebra o modelo interno de Slack/Discord/Notion. **Achado de segurança:** a AX **não** é bloqueada por secure input e escreve em campo de senha — o app precisa detectar e recusar. A corrida do clipboard é na *restauração*, não na escrita.
- [Permissões e ordem de pedido](issues/06-permissoes-e-ordem-de-pedido.md) **(superado em parte — sobrou só Microfone)** — **duas TCC: Microfone e Acessibilidade** (Automação e Input Monitoring descartadas com fonte). O prompt de Acessibilidade **não concede nada** — são 5 passos manuais nos Ajustes, contra 1 clique do microfone. Onboarding up front de 3 passos com re-verificação — **tudo isso caiu junto com a injeção**; sobrou pedir microfone, que é 1 clique.
- [Empacotamento e execução](issues/14-empacotamento-e-execucao.md) **(superado em parte — o addon nativo desapareceu)** — `electron-builder` v26; **ad-hoc não serve** (cada rebuild = prompt novo de Acessibilidade e Keychain), um **Apple Development gratuito basta**; addon nativo via `prebuildify --napi` + `node-gyp-build` (upgrade de Electron sem recompilar); entitlements enxutos (`allow-jit` + áudio); modelo verificado por SHA-256 próprio, porque o script do whisper.cpp não verifica nada; **nunca mudar `productName`** — ele nomeia o `userData` **e** o item no Keychain.
- [Orçamento de latência e duração do ditado](issues/18-orcamento-de-latencia.md) — **~2 s de espera é aceitável, nenhuma alavanca puxada**; duração máxima **~2 min**, ao bater para e processa (nunca descarta). **E o modelo de ativação mudou aqui:** push-to-talk caiu, entrou **clique no ícone (toggle) + atalho global de toggle**, e o texto passou a ir para o **clipboard** em vez de ser injetado. Isso derrubou a permissão de Acessibilidade, o addon nativo e três tickets.
- [Prompt de reescrita](issues/08-prompt-de-reescrita.md) **(limiar corrigido para ~40; saída ficou em texto puro, como decidido originalmente)** — **agressividade escalada pelo tamanho**: até ~40 palavras recebe só pontuação, ≥15 recebe reescrita completa. O agressivo puro ganhou só 1 de 5 amostras — apagou hedge, generalizou nome de arquivo, inventou aprovação, completou frase cortada. Travas duras de `NUNCA MUDE`/`NUNCA ACRESCENTE`. **A saída virou estruturada** em [Aprender correções automaticamente](issues/19-aprender-correcoes-automaticamente.md) — o texto puro com limpeza defensiva que este ticket decidiu não vale mais.
- [Forma do indicador de estado](issues/11-forma-do-indicador-de-estado.md) — **seis estados** (transcrever+reescrever fundidos em "processando"); monocromático `template` exceto **vermelho ao gravar**, respirando a **1,7 s**; fim do ciclo é **check + som curto desligável** — o som resolve o que o ícone não resolve, porque o olhar está no input, não na barra. [Protótipo](https://claude.ai/code/artifact/07629e1d-58ec-4c1d-a5c7-191a3d45cf2f).
- [Cola direto ou revisa antes](issues/09-cola-direto-ou-revisa-antes.md) — **vai direto pro clipboard, sem janela**; o **cru fica em memória até a próxima ditação**, recuperável por "Copiar transcrição crua" no menu. Nada em disco, então não é histórico. Motivo: a distorção vive no texto longo, que é onde você menos pega — e quando pega, o cru já não existe e refazer custa dois minutos de fala.
- [Aprender correções automaticamente](issues/19-aprender-correcoes-automaticamente.md) — **entra no MVP, mas o mecanismo mudou depois do A/B.** Fazer o Groq reportar correções rendeu 1 em 29 — a trava que protege nomes de arquivo impede a detecção. Em vez disso, o editor de dicionário ganha **"adicionar do último ditado"**: mostra o cru, você clica na palavra errada e digita a certa. A fonte da verdade é o usuário, não o modelo. **A saída volta a ser texto puro.**
- [Qual é o atalho](issues/07-qual-e-o-atalho.md) — **`⌃⌥⌘G`**, configurável. F13–F20 eliminadas (é MacBook, elas não existem); `⇧⌘Space` rejeitada apesar de mais confortável, por ser a primeira tecla que qualquer lançador futuro vai querer. **Detecção de conflito é requisito** — `globalShortcut.register` retorna `false` e isso precisa virar aviso visível, nunca falha silenciosa.
- [Janela de microfone aberto](issues/17-janela-de-microfone-aberto.md) — **abre no clique, fecha ao parar.** Decidido pela honestidade do indicador, não pela latência: o ponto laranja vale porque é verdadeiro, e mantê-lo aceso depois de você parar seria um indicador mentindo. Encerra os dois experimentos previstos — **não resta nenhum trabalho de medir no mapa**.
- [Certificado grátis ou pago](issues/22-certificado-gratis-ou-pago.md) — **Apple Development gratuito.** Com a Acessibilidade fora, o pior caso anual virou apenas "recolar a API key" — e o efeito sequer foi confirmado. Sintoma a registrar na spec: após renovação, o app pode pedir a chave do Groq de novo.
- [Quando não há fala](issues/25-quando-nao-ha-fala.md) — **VAD Silero como portão, fora do caminho da transcrição.** Sem portão, 8 de 8 gravações sem fala alucinaram (`Obrigado.`, `E aí`, `Legenda por Sônia Ruberti`). Mas `--vad` *dentro* da transcrição danifica conteúdo — o corpus pegou ele engolindo um nome de arquivo. Portão: zero segmentos = descarta em silêncio; qualquer segmento = transcreve o áudio **inteiro, sem `--vad`**.
- [Corpus de transcrições reais](issues/24-corpus-de-transcricoes-reais.md) — 30 ditações, 630 s. **Baseline: o dicionário precisa de 10 a 30 entradas, não 500.** O Whisper erra de forma estreita e sistemática (palavras curtas em inglês, nomes de ferramenta, e **camelCase sempre**) e acerta o que se temia (`import.spec.ts`, `fixtures.json`, `<sigla-de-domínio>`, `deploy`, `merge`). **Corrigiu três decisões do mapa** e confirmou a estimativa de latência. [Análise](research/corpus/ANALISE.md).
- [Conta e chave do Groq](issues/23-conta-e-chave-do-groq.md) — chave em `~/.config/groq/key` (`600`, fora do repo). `gpt-oss-20b` e `120b` **confirmados** na conta; nenhum Llama, como a research previu. **Limites reais medidos: 250.000 TPM e 500.000 RPD** — 31× o que a doc de Free tier indicava, o que **derruba o gargalo de TPM** que o mapa vinha carregando.
- [A/B de modelo em pt-BR](issues/16-ab-de-modelo-em-pt-br.md) — **`gpt-oss-20b` confirmado**, e o `120b` perdeu no caso mais difícil (manteve as duas versões de uma auto-correção). Travas seguraram: **0 invenções em 9 amostras curtas**, nomes de arquivo intactos. Limiar de 40 funcionou. Latência 0,67 s contra 1,03 s. **Mas o relato de correções falhou (1 de 29)** — a trava que protege nomes de arquivo impede a detecção que o aprendizado precisa.
- [Quando o Groq falha](issues/12-quando-o-groq-falha.md) — **toda falha degrada igual**: cru do Whisper no clipboard, sinalizado por **check vazado** no ícone (sem som distinto). Timeout de **10 s**, folgado de propósito contra o pico medido de 1,27 s. Sem chave, o app funciona em modo cru em vez de bloquear. Preferência explícita para desligar a reescrita quando o texto não pode ser alterado.
- [Falhas locais](issues/26-falhas-locais.md) — **modelo baixa no onboarding**, com progresso, antes de liberar o uso; SHA-256 verificado por conta própria. Binário ausente = não abre (única falha em que recusar é melhor que degradar). Device de áudio trocando no meio: **transcreve o que capturou**, nunca descarta. Atalho re-registrado defensivamente em `powerMonitor`.
- **[Montar a spec final](issues/15-montar-a-spec-final.md) — DESTINO ALCANÇADO.** A spec está em [`spec.md`](spec.md). Nenhuma lacuna nova apareceu ao consolidar; as cinco questões abertas estão declaradas na seção 13 e nenhuma bloqueia a implementação.

## Not yet specified


- **Idioma.** `pt-BR` fixo vs seleção vs auto-detect do Whisper. Depende de quão bem o auto-detect se comporta em falas curtas e em português com termos técnicos em inglês misturados.
- **Consumo de memória e energia.** Electron rodando o tempo todo na barra de menu tem custo de RAM. Somou-se um custo de energia: se o device de áudio ficar aberto, o Audio Service mantém uma callback do CoreAudio acordando a cada poucos ms, e isso aparece no consumo em notebook. Ainda não medido.

## Out of scope

- **Colar automaticamente no input focado** — era o núcleo da ideia original, e saiu em [Orçamento de latência e duração do ditado](issues/18-orcamento-de-latencia.md): o texto vai para o clipboard e o usuário cola. Preço aceito: um `⌘V` manual por ditação. Preço evitado: a permissão de Acessibilidade e toda a superfície de injeção. Pode voltar depois, como esforço novo.
- **Comportamento quando o foco muda durante o processamento** — [ticket fechado](issues/13-foco-muda-durante-o-processamento.md). Sem injeção não há alvo de foco.
- **Matriz de injeção nos apps reais** — [ticket fechado](issues/20-matriz-de-injecao-nos-apps-reais.md). Não há injeção a testar.
- **Restaurar o clipboard do usuário** — [ticket fechado](issues/21-restaurar-o-clipboard.md). O clipboard virou o destino do texto, por design; o app é dono dele.
- **Push-to-talk (segurar para falar)** — descartado em [Orçamento de latência e duração do ditado](issues/18-orcamento-de-latencia.md). Tecla confortável de segurar exigiria event tap (keylogger); acorde de quatro teclas não se segura por dois minutos.

- **Notarização, distribuição e auto-update** — o destino é uso pessoal do autor, não um produto distribuído. **Ressalva:** *assinar* o app **não** é fora de escopo — é requisito duro por duas razões independentes: arm64 não executa código nativo sem assinatura válida, e sem identidade estável o Keychain e o TCC re-perguntam a cada rebuild. Decidido em [Empacotamento e execução](issues/14-empacotamento-e-execucao.md); a escolha de certificado está em [Certificado grátis ou pago](issues/22-certificado-gratis-ou-pago.md).
- **Onboarding de permissões para usuário leigo** — mesma razão.
- **Comandos de voz** ("nova linha", "vírgula", "apagar isso") — escopo adicional que não bloqueia o núcleo.
- **Histórico de transcrições** — idem.
- **Transcrição em nuvem** — decidido que o áudio bruto nunca sai da máquina. Só o texto vai pro Groq.
- **Streaming palavra-a-palavra** — entrega é batch; o texto vai para o clipboard de uma vez quando você para a gravação.
- **Formatação sensível ao contexto do app** (detectar se é commit/e-mail/chat e formatar de acordo) — exigiria inspecionar qual app está em primeiro plano, o que traz de volta a Accessibility API que o desenho atual eliminou. Substituído pela heurística de tamanho em [Prompt de reescrita](issues/08-prompt-de-reescrita.md).
- **Swift + AppKit nativo, e Tauri** — descartados como stack em favor de Electron.
- **App Sandbox** — permanece fora, mas **por outra razão que a original**. A justificativa era que a Accessibility API é proibida sob sandbox; com a injeção removida, esse argumento caiu. O que sustenta hoje é que sandbox só importa para a App Store, e distribuição está fora de escopo. **Se o destino for redesenhado para distribuir, isto vira pergunta aberta de novo** — em especial se um app sandboxed consegue dar `spawn` no `whisper-cli` embarcado. Não investigado.
